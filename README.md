# Travel Map

## 概要
旅行先を投稿・共有できるSNS型マップアプリです。

## テーマを選んだ理由
私は旅行が好きで、旅行先で撮影した写真や動画を多く残しています。  
その中で、「自分が実際に行って良かった場所や体験を、他の人にも共有したい」と思うようになりました。  
また、他の人の投稿を見て旅行先を決めることも多く、SNSとマップを組み合わせることで、ユーザー同士が旅行の魅力を共有し、新しい場所へ行くきっかけになるアプリを作りたいと考え、このテーマを選びました。

## ターゲットユーザー
旅行やお出かけが好きなすべての人を対象としています。  
年齢制限は特になく、若い世代から高齢者まで幅広いユーザーが利用できることを想定しています。
