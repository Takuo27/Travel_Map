# 機能一覧

|機能ID|機能名|機能概要|
|---|---|---|
|F001|ユーザー登録機能|メールアドレスとパスワードを使用してユーザー登録を行う|
|F002|ログイン機能|登録済みユーザーがログインを行う|
|F003|ログアウト機能|ログイン中ユーザーがログアウトを行う|
|F004|プロフィール表示機能|ユーザー情報および投稿一覧を表示する|
|F005|プロフィール編集機能|ユーザー名やプロフィール画像を変更する|
|F006|投稿作成機能|旅行先の写真・動画・説明文・位置情報を投稿する|
|F007|投稿一覧表示機能|投稿一覧を時系列で表示する|
|F008|投稿詳細表示機能|選択した投稿の詳細情報を表示する|
|F009|投稿編集機能|自身の投稿内容を編集する|
|F010|投稿削除機能|自身の投稿を削除する|
|F011|画像アップロード機能|旅行先の画像をアップロードする|
|F012|動画アップロード機能|旅行先の動画をアップロードする|
|F013|マップ表示機能|投稿場所をマップ上へ表示する|
|F014|現在地取得機能|ユーザーの現在地情報を取得する|
|F015|位置情報登録機能|投稿時に位置情報を登録する|
|F016|いいね機能|投稿へいいねを行う|
|F017|コメント機能|投稿へコメントを行う|
|F018|検索機能|キーワードによる投稿検索を行う|
|F019|地域検索機能|地域別に投稿検索を行う|
|F020|レスポンシブ対応機能|スマートフォン・タブレット・PC画面へ対応する|
|F021|エラーメッセージ表示機能|入力エラーや認証エラー時にメッセージを表示する|
|F022|認証機能|ログインユーザーのみ投稿や編集を可能とする|
